AIoT Multiple Linear Regression & Feature Selection Explorer

Designed for regression model diagnostics, Occam's razor parsimony validation, and comparative machine learning feature selection analysis. Fully static and optimized for deployment on GitHub Pages.

Methodology & Technical References
Process: CRISP-DM (Cross-Industry Standard Process for Data Mining).
Algorithms: Lasso (L1 regularization), Forward Stepwise Selection, Backward Elimination, Recursive Feature Elimination (RFE), Elastic Net, Mutual Information, Variance Threshold.
Stack: Pure Vanilla HTML5, Modern CSS3, JavaScript (ES6+), and Chart.js.
